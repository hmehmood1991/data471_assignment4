# DATA471 Assignment IV

Solutions to Exercises 1 and 2.

## Reproduce
Requires R with `rmarkdown` and `fpp2` installed.

    install.packages(c("rmarkdown", "fpp2"))

Then render:

    Rscript -e 'rmarkdown::render("Assignment4.Rmd")'

Note: Exercise 1 runs a Monte Carlo simulation, so the first knit takes a few minutes.
